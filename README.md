# آي ستور — متجر إكسسوارات ومنتجات Apple

متجر إلكتروني متكامل للسوق الليبي: واجهة عربية RTL بالكامل، أسعار بالدينار الليبي، دفع عند الاستلام، ولوحة تحكم منفصلة تتحكم بكل شيء.

## التقنيات

- **Next.js 14** (App Router) + TypeScript
- **Tailwind CSS** + **Framer Motion** (أنميشن وحركات احترافية: سلايدر رئيسي متحرك، ظهور عند التمرير، سلة منزلقة، بحث فوري)
- **SQLite** (better-sqlite3) — قاعدة بيانات مدمجة، لا تحتاج خادم قواعد خارجي
- لوحة إدارة منفصلة على `/admin`

## المزايا

### المتجر
- سلايدر رئيسي متحرك قابل للتعديل من لوحة التحكم
- 30 منتجاً جاهزاً في 7 تصنيفات (قابلة كلها للتعديل والحذف والإضافة)
- بحث فوري + فلاتر (تصنيف، سعر، عروض، ترتيب)
- صفحة منتج بتقييم ومخزون ومنتجات مشابهة
- سلة تسوق + إتمام طلب مع رسوم توصيل لأكثر من 25 مدينة ليبية
- شحن مجاني فوق حد معين (يُضبط من الإعدادات)
- صفحة نجاح الطلب برقم تتبع + صفحة «تتبع طلبك»
- صفحة «من نحن» بسياسات قابلة للتعديل

### لوحة التحكم `/admin`
- لوحة معلومات: مبيعات، طلبات، رسم بياني لآخر 7 أيام، تنبيهات المخزون المنخفض
- إدارة المنتجات (إضافة/تعديل/حذف، صور، أسعار، خصومات، مخزون، شارات، تمييز)
- إدارة التصنيفات، شرائح الرئيسية، البنرات الترويجية
- إدارة الطلبات وحالاتها (جديد → مؤكد → مشحون → مكتمل / ملغي) مع استرجاع المخزون عند الإلغاء
- إدارة مدن التوصيل ورسومها
- إعدادات المتجر: الاسم، الوصف، شريط الإعلانات، العملة، التواصل، روابط السوشيال، السياسات
- إدارة المشرفين وتغيير كلمات المرور
- رفع صور مباشر من اللوحة

## التشغيل

```bash
npm install
npm run build
npm start        # الإنتاج على http://localhost:3000
# أو للتطوير:
npm run dev
```

قاعدة البيانات (`istore.db`) تُنشأ وتُبذَر تلقائياً عند أول تشغيل. لتغيير مسارها: `DB_PATH=/path/to/db.sqlite`.

## دخول لوحة التحكم

- الرابط: `/admin`
- الافتراضي (تطوير محلي فقط): المستخدم `admin` وكلمة المرور `admin123` — في الإنتاج حدّد `ADMIN_USERNAME` و`ADMIN_PASSWORD` كمتغيرات بيئة وغيّر كلمة المرور فوراً
- **غيّر كلمة المرور فوراً** من: لوحة التحكم ← المشرفون

## بنية المشروع

```
src/
  app/(store)/     صفحات المتجر (رئيسية، منتجات، منتج، سلة، دفع، تتبع، من نحن)
  app/admin/       لوحة التحكم (دخول + لوحة منفصلة)
  app/api/         واجهات API (طلبات، بحث، تتبع + كل عمليات الإدارة)
  components/      مكونات المتجر ولوحة التحكم
  lib/             قاعدة البيانات، البذر، الجلسات، الإعدادات
public/images/     صور المنتجات والتصنيفات
public/uploads/    الصور المرفوعة من لوحة التحكم
```

## ميزات أُضيفت لاحقاً

- **متغيرات المنتج (Variants):** خيارات (مثل اللون والسعة) ومتغيرات لكل منتج بسعر ومخزون خاص، تُدار من نموذج المنتج في لوحة التحكم، ويختارها العميل في صفحة المنتج، والسلة والطلبات تحفظ المتغير المختار.
- **زر واتساب في صفحة الطلب:** رسالة جاهزة للعميل تُفتح بضغطة من صفحة تفاصيل الطلب.
- **إشعارات تيليجرام للمالك:** عند كل طلب جديد. الـ Token ومعرّف المحادثة (Chat ID) يُدخلان من صفحة الإعدادات `/control` (فيها زر اختبار). إن لم يُحفظا في الإعدادات يُستعمل المتغيران `TELEGRAM_BOT_TOKEN` و`TELEGRAM_CHAT_ID`. لا تضع هذه القيم في الكود أو في هذا الملف.
- **بحث حي في صفحة المنتجات (لوحة التحكم):** يتصفى الجدول مع كل حرف بدون Enter، والمطابقة على اسم المنتج فقط (يحتوي النص في أي مكان من الاسم)، وتفريغ الحقل يعيد كل المنتجات. لا يوحّد الحروف العربية (أ/ا/إ وة/ه) حالياً.
- **أزرار الرجوع:** زر «رجوع بدون حفظ» في نموذج المنتج، وزر «رجوع للطلبات» في صفحة الطلب يحافظ على تبويب/فلتر القائمة السابقة. باقي صفحات اللوحة تعدّل داخل الصفحة نفسها فلا تحتاجه.

## متغيرات البيئة

| المتغير | الاستخدام |
|---|---|
| `DB_PATH` | مسار قاعدة SQLite |
| `ADMIN_USERNAME` / `ADMIN_PASSWORD` | مشرف أول عند التهيئة (إلزامي في الإنتاج) |
| `SETTINGS_USERNAME` / `SETTINGS_PASSWORD` | دخول صفحة `/control` (الافتراضي المحلي فقط: control / control123) |
| `TELEGRAM_BOT_TOKEN` / `TELEGRAM_CHAT_ID` | بديل لإعدادات تيليجرام في `/control` |
| `RESEND_API_KEY` / `NOTIFY_EMAIL` / `RESEND_FROM` | إشعارات الطلبات بالبريد (اختياري) |

## النشر على Render

المتجر منشور على Render (خطة مجانية) من فرع `main`. القرص مؤقت: **كل نشر جديد يعيد إنشاء قاعدة البيانات من البذر** فتضيع الإعدادات المحفوظة (مثل Token تيليجرام) والطلبات والتعديلات. للإبقاء على الإعدادات استعمل متغيرات البيئة أعلاه، وللإبقاء على البيانات استعمل قرصاً دائماً أو قاعدة بيانات خارجية.

## نسخة PHP / MySQL

موجودة في فرع `php` من نفس المستودع (نفس المزايا بواجهة PHP)، وتُسلَّم أيضاً كملف `istore-php.zip` في Google Drive. عند كل تحديث يُنشأ zip جديد ويُحذف القديم.

## واجهة API v1 (نسخة PHP)

تحت `api/v1/` في فرع `php`: المصادقة والحساب، المنتجات، التصنيفات، الماركات، السلة، الكوبونات، الطلبات، التقييمات، المفضلة، تنبيهات المخزون، والإعدادات. يستعملها تطبيق Flutter في المستودع `istore-app` (لم يُبنَ ولم يُتحقق منه كملف APK بعد).
