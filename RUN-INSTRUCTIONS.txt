========================================
  آي ستور — متجر إكسسوارات Apple
  تعليمات التشغيل محلياً (على جهازك)
========================================

المتطلبات:
- Node.js نسخة 18 أو أحدث (حمّله من https://nodejs.org — زر LTS)
- لا يحتاج XAMPP ولا أي قاعدة بيانات خارجية — قاعدة SQLite مدمجة وتُنشأ تلقائياً

خطوات التشغيل (من داخل مجلد المشروع):
1) npm install
2) npm run build
3) npm start

ثم افتح المتصفح على:
- المتجر:        http://localhost:3000
- لوحة التحكم:   http://localhost:3000/admin

دخول لوحة التحكم (للتطوير المحلي فقط):
- المستخدم: admin
- كلمة المرور: admin123
- غيّرها فوراً من صفحة "المشرفون" داخل اللوحة.
- للإنتاج: اضبط ADMIN_USERNAME و ADMIN_PASSWORD كمتغيرات بيئة (انظر .env.example)

قاعدة البيانات:
- تُنشأ وتُبذر تلقائياً بـ30 منتج و26 مدينة عند أول تشغيل (ملف istore.db).
- لإعادة الضبط: احذف ملف istore.db وأعد التشغيل.

إشعارات الطلبات بالبريد (اختياري محلياً):
- انسخ .env.example إلى .env.local واملأ RESEND_API_KEY و NOTIFY_EMAIL.

ملاحظات:
- لا تشارك ملف .env.local مع أحد — فيه مفاتيحك السرية.
- الكود الكامل محفوظ أيضاً على: https://github.com/6599p5g2wq-arch/istore
